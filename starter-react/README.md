# React starter — KOTES401

Tämä on React‑versio studion starter‑projektista. Opiskelijat täydentävät komponenttia istunnon aikana.

Käynnistä paikallisesti:

1. npm install
2. npm run dev

Tehtävät:
- Refaktoroi lisäysfunktio (`handleAdd`) käyttäen LLM:ää.
- Lisää Poista‑painike ja localStorage‑tuki.
- Tee 1 commit ja näytä prompt + LLM‑vastaus.

# Solution — opettajan ratkaisu (branch `solution`)

Tämä branch sisältää opettajan ratkaisun React‑tehtävään sekä selitykset.

Sisältö:
- `react-solution/` — valmis React‑sovellus (lisäys, poisto, merkintä, localStorage)

Käynnistä:

1. cd solution/react-solution
2. npm install
3. npm run dev

Huom: tämä on opettajan ratkaisu — opiskelijoille jaetaan `main`‑branchin `starter/` tai `starter-react/`.
